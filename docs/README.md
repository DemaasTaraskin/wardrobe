# Приложение «Гардероб» — сайт

Статические файлы: HTML, CSS и модули ES — сборка не нужна. Данные берутся из Supabase
напрямую из браузера, защита — RLS (см. [DATA.md](../DATA.md)). Claude в приложении не участвует.

| Файл | Что делает |
|---|---|
| `index.html` | разметка всех экранов: вход, подбор, лук, гардероб |
| `app.js` | вход по почте, вкладки, запуск |
| `pick.js` | подбор по температуре и ситуации, экран лука, оценки, «надел сегодня» |
| `wardrobe.js` | сетка вещей, фильтры, правка карточки |
| `lib.js` | клиент Supabase, справочники, подписанные ссылки на фото |
| `config.js` | адрес проекта и publishable-ключ. **Собирается командой `python tools/make_config.py`**, руками не правим |
| `sw.js` | кэш оболочки, чтобы открывалось без сети; данные и фото не кэшируются |
| `icons/` | иконка для экрана телефона |

## Публикация

1. GitHub → репозиторий `wardrobe` → **Settings → Pages** → Source: *Deploy from a branch*,
   ветка `main`, папка `/docs` → Save.
2. Через минуту сайт живёт по адресу `https://demaastaraskin.github.io/wardrobe/`.

## Что настроить в Supabase (один раз)

**Authentication → URL Configuration**
- *Site URL*: `https://demaastaraskin.github.io/wardrobe/` — на этот адрес ведёт ссылка из письма.
- *Redirect URLs*: добавить `https://demaastaraskin.github.io/wardrobe/**`
  и `http://localhost:8765/**` — второй нужен для локальной проверки.

**Authentication → Emails** — в шаблоны *Magic Link* и *Confirm signup* добавить строку:

```html
<p>Код: {{ .Token }}</p>
```

Без неё в письме будет только ссылка: приложение и так пустит по ней, но шесть цифр на телефоне
удобнее. Встроенная почта Supabase шлёт **2 письма в час** — это не ошибка приложения.

Регистрация закрыта: аккаунт заводится приглашением (Authentication → Users → Add user).

## Локальный запуск

```bash
python -m http.server 8765 --directory docs
```

Открыть `http://localhost:8765`. Service worker на `http://` намеренно не включается,
чтобы правки были видны сразу.

## Иконка на экране телефона

Открыть сайт → «Поделиться» → «На экран Домой» (iOS) или меню → «Добавить на главный экран»
(Android). Приложение запустится без адресной строки, вход запомнится.
