# Гардероб: проект

Личное приложение-гардероб. Пользователь вводит температуру и выбирает ситуацию, приложение показывает 2–3 готовых лука. Им пользуются двое: владелец и ещё один человек, у каждого свой гардероб.
Текущий этап и чекбоксы — в [PLAN.md](PLAN.md). Сверяйся с ним в начале каждой сессии.

## Где что лежит
- `C:\Users\manyl\wardrobe-photos\` — 97 оригиналов фото вещей (PNG с прозрачным фоном, ~340 МБ). Папка **намеренно вне OneDrive**: не переносить её и не копировать оригиналы в `clothes/`.
- `miro_board.json` — выгрузка с доски Miro: группы, подписи к вещам (в них есть температурные диапазоны и уровень формальности), стикеры.
- `reference_look.md` — эталон стиля (Frame 24). Чёрный джемпер и молочный лонгслив в нём — два альтернативных варианта, а не слои.
- `.claude/skills/miro-board-export/` — скил выгрузки фото и текстов из Miro. `miro-board-export.skill` — он же одним файлом для отправки другим людям.

## Правила
- **Miro:** только через скил `miro-board-export`, только по публичной ссылке «Can view» и только во встроенном браузере без входа в аккаунт. У владельца есть вторая, приватная доска, к ней не прикасаться.
- **Приватность:** фото, каталог, `miro_board.json`, `.env` и ключи никогда не попадают в git и в публичный доступ. Репозиторий на GitHub Free публичный. Ключи в `.env` вписывает сам пользователь.
- **Внешние действия** (запись в Supabase, push на GitHub, публикация сайта) — только после подтверждения пользователя.
- **Луки генерирует Claude в чате** (Claude Code). В самом приложении нет вызовов Claude и раздела покупок: покупки перенесены во вторую фазу.

## Как работать с владельцем
- Общаться по-русски.
- Вопросы задавать интерактивно, с вариантами ответа (AskUserQuestion), а не открытым текстом.
- **Перед началом каждого этапа из PLAN.md рекомендовать настройки**: модель, effort, продолжать эту сессию или открыть новую, режим разрешений. К каждой рекомендации одна строка «почему». Effort пользователь выставляет сам в окне чата. Базовые рекомендации (Opus 5):

  | Этап | Effort | Сессия |
  |---|---|---|
  | 1. Договор о данных | xhigh | новая |
  | 2. Каталог 97 вещей | high | можно продолжить после этапа 1 |
  | 3. База и скил | high (xhigh на сложных багах) | новая, если контекст уже длинный |
  | 4. Приложение | high | новая |
  | 5. Генерация луков | xhigh | новая |
  | 6. Разбор отзывов | high | новая |
  | 7. Второй пользователь | high | любая |

  Уровень max не нужен. Режим разрешений auto подходит для всех этапов.
- После каждого этапа отмечать выполненные пункты в PLAN.md.
